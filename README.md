## 🎯 ¿Qué es Fortalezas Co³?

**Fortalezas Co³** es la plataforma web que digitaliza **Conversaciones de Fortalezas Co³**, una herramienta física de 63 tarjetas creada por Karen Pérez Molina. La experiencia combina **Indagación Apreciativa**, **Psicología Positiva**, **Neurociencias Aplicadas** y **Sabiduría Ancestral de los Andes** para generar conversaciones que transforman equipos, relaciones y culturas organizacionales.

La plataforma está orientada a tres perfiles de uso:

| Perfil | Propósito |
|---|---|
| 🧠 **Autoconocimiento personal** | Descubrir y explorar fortalezas individuales |
| 👥 **Dinámicas de equipo** | Facilitar sesiones grupales de reconocimiento, cohesión y colaboración |
| 🏢 **Consultoría organizacional** | Herramienta de apoyo para coaches, líderes y facilitadores |

La interfaz combina glassmorphism, animaciones de partículas en tiempo real y una arquitectura completamente orientada a datos (*data-driven UI*), garantizando una experiencia fluida y visualmente impactante sin sacrificar rendimiento.

## 🌱 Las raíces que sostienen el proyecto

Toda creación viva tiene raíces. Las de Conversaciones de Fortalezas Co³ nacen del encuentro entre ciencia, conciencia y sabiduría ancestral. Estas cuatro raíces se entrelazan como un tejido vivo y son el sustento invisible de cada tarjeta, cada interacción y cada conversación que la plataforma activa.

**🔍 Indagación Apreciativa**
Invita a mirar lo que da vida: descubrir fortalezas, logros y sueños como fuente de transformación. Nos recuerda que cada conversación puede construir futuro cuando elegimos preguntar desde lo que funciona.

**🧠 Psicología Positiva**
Activa las fortalezas humanas y el bienestar sostenible. Nos enseña que florecer no es ausencia de dificultad, sino la capacidad de encontrar sentido, energía y propósito incluso en los desafíos.

**🔬 Neurociencias Aplicadas**
Nos ayudan a entender cómo el cerebro responde a las emociones, al reconocimiento y al diálogo genuino, convirtiendo cada conversación en una oportunidad para crear nuevas conexiones y aprendizajes.

**🏔️ Sabiduría Ancestral de los Andes**
Recuerda lo sagrado de lo cotidiano. Inspira a conversar desde el respeto por la vida, la reciprocidad y la interconexión de todo lo existente, honrando el equilibrio entre dar y recibir.

## 🃏 La herramienta: 63 tarjetas vivas

Conversaciones de Fortalezas Co³ está conformada por **63 tarjetas**, cada una creada con intención, color y propósito, pensada para evolucionar con cada equipo y cada conversación que la habita.

### 🟣 Virtudes y Fortalezas — 30 tarjetas
*El corazón de la herramienta.*

Reúne **6 Virtudes** que representan cualidades esenciales del ser humano y **24 Fortalezas** que las expresan en la vida cotidiana.

| Virtud | Descripción |
|---|---|
| 🌟 Sabiduría | Amor por el conocimiento y la perspectiva amplia |
| 🦁 Coraje | Valentía, autenticidad y perseverancia |
| ❤️ Humanidad | Amor, amabilidad e inteligencia social |
| ⚖️ Justicia | Equidad, liderazgo y trabajo en equipo |
| 🧘 Templanza | Autorregulación, humildad y prudencia |
| ✨ Trascendencia | Gratitud, esperanza, humor y espiritualidad |

Cada tarjeta invita a descubrir *el poder de esa fortaleza*, a practicarla con sencillez y a explorarla mediante **preguntas generativas** y **microprácticas** que expanden la mirada y el lenguaje.

---

### 🩷 Caminos Co³ — 15 tarjetas
*El alma conversacional de la herramienta.*

Organizados en tres caminos, cada uno con cinco categorías que facilitan el diálogo, la reflexión y el movimiento hacia la acción:

```
CONECTAR ──────── Abre espacios de confianza y vínculo
    ↓
CONSTRUIR ─────── Impulsa la colaboración y la visión compartida
    ↓
CONCRETAR ─────── Orienta hacia acuerdos, decisiones y acción
```

Pueden usarse solos o en secuencia, para construir una conversación completa de principio a fin.

---

### 🟦 Neurotips — 5 tarjetas
*El puente entre la ciencia y la experiencia.*

Traducen conceptos de Neurociencias Aplicadas en prácticas simples y cotidianas. Ideales como apertura de reuniones, recordatorios o inspiración en momentos de tensión. Ayudan a traer conciencia sobre cómo el cuerpo, las emociones y el lenguaje influyen en el desempeño y la conexión.

---

### 🟩 Prácticas Rituales — 5 tarjetas
*El espíritu que da vida al encuentro.*

Proponen acciones simbólicas y significativas: agradecer, cerrar etapas, liberar tensiones o abrir nuevos ciclos. Ideales para momentos de transición o cierre de proyectos, traen presencia, gratitud y energía renovada.

---

### 🌳 Esquema del Árbol + Tarjeta de Instrucciones
El **Árbol de Conversaciones de Fortalezas** representa la estructura viva que sostiene la herramienta: raíces que nutren, tronco que conecta, ramas que se expanden. La tarjeta de instrucciones acompaña el recorrido con una guía práctica para usar la herramienta con libertad y propósito.

## ✨ Características de la plataforma

| Característica | Descripción |
|---|---|
| 🌊 **Partículas en tiempo real** | Motor de simulación matemática sobre HTML5 Canvas con impacto mínimo de CPU |
| 🪟 **Glassmorphism** | Sistema visual coherente con transparencias, blur y profundidad |
| 📱 **Mobile First** | Layouts fluidos optimizados para carga instantánea en dispositivos móviles |
| 🎴 **Motor de tarjetas** | Interacción dinámica e individual por tarjeta con estados y animaciones |
| 📊 **Data-driven UI** | Toda la lógica de fortalezas y categorías proviene de estructuras JSON desacopladas |
| ♿ **Accesibilidad** | HTML5 semántico estructurado para lectores de pantalla y navegación por teclado |
| 🔐 **Login inmersivo** | Gateway de seguridad con pantalla de entrada experiencial |

## 🛠️ Stack Tecnológico

> **Filosofía:** Cero dependencias pesadas — *Vanilla Tech Stack* — para garantizar tiempos de carga instantáneos.

```
HTML5 Semántico
└─ Estructura accesible y semántica orientada a SEO y accesibilidad

CSS3 Avanzado
├─ Variables nativas CSS (design tokens centralizados)
├─ Glassmorphism (backdrop-filter, transparencias en capas)
├─ CSS Grid + Flexbox (layouts fluidos y responsivos)
└─ Media Queries críticas (mobile-first breakpoints)

JavaScript ES6+
├─ Arquitectura asíncrona (async/await, Promises)
├─ Control de estados locales sin frameworks externos
└─ Módulos desacoplados por responsabilidad

HTML5 Canvas API
└─ Simulación matemática de partículas en tiempo real
   (vectores, velocidades, colisiones — optimizado con requestAnimationFrame)
```

```

│

├── 🏠 home.html            # Dashboard interactivo principal
├── 🗂️ category.html        # Selector matricial de categorías
└── 🎴 card.html            # Motor dinámico de tarjeta individual
```

## 🔄 Flujo de la Aplicación

```
index.html (Login)
      │
      ▼  [Autenticación exitosa]
home.html (Dashboard)
      │
      ├──► Virtudes & Fortalezas
      ├──► Caminos Co³ (Conectar / Construir / Concretar)
      ├──► Neurotips
      └──► Prácticas Rituales
                  │
                  ▼  [Selección de categoría]
          category.html (Matriz de categorías)
                  │
                  ▼  [Selección de tarjeta]
          card.html (Tarjeta individual con micropráctica y pregunta generativa)
```

Cada vista carga los datos necesarios desde los JSON de `/data/` y renderiza dinámicamente la UI, sin recargas de página completas entre estados.

## 🚀 Instalación y Uso

### Requisitos

- Navegador moderno con soporte para ES6+, CSS Grid y Canvas API
- Servidor HTTP local o acceso directo al sistema de archivos

### Inicio rápido

```bash
# 1. Clonar el repositorio
git clone https://github.com/KrisAndre-25/Fortalezas-co3.git

# 2. Ingresar al directorio
cd Fortalezas-co3

# 3. Levantar un servidor local
# Opción A — Python (incluido en la mayoría de sistemas):
python -m http.server 3000

# Opción B — Node.js con npx:
npx serve .

# Opción C — VS Code: instalar la extensión "Live Server" y abrir index.html

# 4. Abrir en el navegador
http://localhost:3000
```

### Deployment

El proyecto es completamente estático — compatible con cualquier hosting de archivos:

```bash
# Netlify (drag & drop o CLI)
netlify deploy --dir .

# GitHub Pages
# Activar desde Settings → Pages → Deploy from branch main

# Vercel
vercel --prod
```

## 🎨 Diseño y Experiencia de Usuario

### Sistema de Diseño

El sistema visual está construido sobre **CSS custom properties** (variables nativas), lo que permite theming consistente desde un único punto de control, glassmorphism coherente con layers de profundidad definidos, y paleta cromática orquestada con tokens semánticos.

### Principios de Diseño

Cada decisión de UX/UI replica la filosofía del método Co³: la experiencia debe ser **inmersiva**, **apreciativa** y **progresiva**.

- **Inmersión progresiva** — Cada pantalla introduce al usuario más profundamente en la experiencia, igual que el recorrido físico de las tarjetas
- **Microinteracciones significativas** — El feedback visual refuerza cada acción del usuario
- **Jerarquía visual clara** — Tipografía, espaciado y color guían la atención naturalmente
- **Contraste accesible** — Ratios WCAG AA respetados en todos los componentes interactivos
- **Lenguaje apreciativo** — Los textos de la interfaz hablan desde las fortalezas, no desde el déficit
